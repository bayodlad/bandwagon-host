# 搬瓦工购买指南：套餐选择、支付宝下单与开通后检查

第一次购买 VPS，容易把注意力集中在价格上，却忽略流量、付款周期和机房范围。下面以搬瓦工现有参考套餐为例，从需求判断、套餐比较到下单和初始管理，梳理一次完整的选购过程。具体价格、库存、机房及结算选项可能变化，提交订单前请以相应页面显示为准。

## 搬瓦工是什么，适合哪些需求？

搬瓦工（BandwagonHost）是加拿大 IT7 Networks 旗下的 VPS 服务商。VPS 可以理解为供用户远程管理的一台虚拟服务器：网站和应用的部署者可以用它运行自己的服务，想学习 Linux 的用户也可以用它练习服务器管理。购买服务器本身不等于完成应用部署，操作系统、账户安全和日常维护仍需要使用者处理。

服务提供 KiwiVM 控制面板，可用于查看服务器状态、重装系统、制作快照和切换支持的机房。它与通过 SSH 登录服务器是不同的管理入口：面板侧重服务器级操作，SSH 则让用户进入系统执行管理任务。对新手来说，理解这两个入口有助于在系统无法正常连接时，先从面板检查状态。

选购前可以先写下四件事：愿意支付的金额和周期、预计每月流量、希望使用的机房，以及是否需要保留切换位置的余地。如果只是练习，较低的年付成本可能更重要；如果有持续运行的业务，则需要把实际流量和机房要求一起考虑。参考资料没有列出各套餐的完整硬件配置，因此不要仅凭下表推断内存、处理器或磁盘是否满足应用要求，应在产品页面核对。

## 机房和线路怎么选

机房位置决定服务器所在地点，而线路描述的是网络连接方式；它们都值得看，但不能单独作为实际访问体验的保证。用户所处地区、使用的网络以及访问时段也可能影响连接表现。先明确主要使用者在哪里，再在套餐允许的机房中比较位置与线路，比只按机房名称选择更有针对性。

参考资料在 CN2 GIA-E 的机房示例中列出 DC6、DC9、日本大阪软银和荷兰联通等选择。若关心这些地点或线路，先核对所选套餐页面是否仍提供，再决定初次下单的位置。KVM 入门的参考列表包含 DC3 CN2，但不应据此认为所有系列拥有相同的机房选择。

参考资料提到多数套餐可在 KiwiVM 切换机房，而香港套餐使用香港专属机房。换机房前应查看当前支持范围和费用，并先做好数据备份；切换后 IP 可能改变，依赖原 IP 的连接信息也需要重新核对。不要把可切换理解为所有套餐都能互换位置，也不要假设迁移一定不会影响数据或服务。

## 搬瓦工购买教程：从购物车到付款

### 1. 选择产品并确认订单周期

从上表进入对应产品，或先[查看在售套餐与当前价格](https://bit.ly/BanWaGon)。在产品页面核对套餐名称、月流量、机房选项和付款周期；若页面还列有应用所需的硬件配置，也应一并检查。选择好周期与初始机房后，点击 **Add to Cart** 加入购物车。

购物车是最后检查选择是否正确的重要位置：确认产品没有选成同系列的另一档，价格对应的是预期的月、季或年周期，机房也符合需求。如果页面上的信息与上表不同，以页面当前显示为准；不确定时先返回修改，不要依赖付款后再处理。

### 2. 验证优惠码并进入结算

购物车中的 **Promotional Code** 是填写优惠码的位置。如果手头有适用的代码，可输入后点击 **Validate Code**，再检查页面是否接受以及订单金额如何变化。参考资料没有提供具体代码，因此这里不列出代码，也不预设折扣一定适用于当前订单或续费。

没有可用优惠码时，仍可按页面显示的金额决定是否继续。核对订单后点击 **Checkout**，进入账户信息和支付方式页面。留意折扣后的应付金额与付款周期，避免只看到折扣提示而忽略实际总额。

### 3. 填写账户资料并选择支付方式

根据结算表单要求如实填写账户资料，尤其使用能够正常接收邮件的邮箱，并设置安全、独立的账户密码。开通信息会发送到邮箱，邮件地址填错会影响后续查收。参考资料建议注册时关闭代理；这是一项注册注意事项，并不能保证订单一定通过审核。

参考流程中，国家选择 **China** 后可以选择 **Alipay**，即支付宝；页面也提到 **UnionPay** 等付款方式。可用选项以实际结算页面为准。如果没有显示支付宝，先检查国家选择和当前页面提供的选项，不要在未确认订单内容的情况下反复提交。

阅读并确认服务条款后，按页面要求勾选条款，点击 **Complete Order**。选择支付宝时，参考流程会跳转至付款页面，通过手机扫码完成支付。付款前再次确认收款页面和应付金额，完成后留意订单状态及邮箱信息。

## 开通后：邮件、KiwiVM 与首次登录

收到开通邮件后，先核对服务器 IP、SSH 端口和初始登录信息，并妥善保管。端口应以邮件或面板显示的实际值为准，不要默认使用某个端口。如果邮件未及时出现，可以先检查邮箱及垃圾邮件，再查看账户中的订单或服务状态。

登录账户后，按 **My Services → KiwiVM Control Panel** 进入控制面板，查看服务器状态是否为 **Running**。随后可使用 SSH 工具连接邮件中的 IP 和端口：参考资料举例 Windows 可用 Xshell 或 PuTTY，Mac 可使用终端。首次用初始密码登录后，修改密码并保存新的凭据；不要把账户或服务器密码公开分享。

面板还提供重装系统和快照等操作。重装适合需要重新安装系统时使用，快照可用于保留服务器状态；这些操作可能影响现有数据或服务，执行前应确认所选功能及其当前规则，并准备好必要的备份。如果需要更换 IP，参考资料提到可在面板申请付费换 IP，也提到部分套餐可免费切换机房；实际费用、可用性和切换后的影响应在操作页面确认。

## 常见问题

### 找不到支付宝或其他支付选项怎么办？

先检查结算资料中的国家选择，参考流程是在选择 **China** 后显示支付宝。不同时间或账户可见的支付方式可能不同，最终以结算页面为准。若选项仍未出现，先不要把订单视为已付款；确认页面状态后再决定如何继续。

### 应该选月付、季付还是年付？

先看目标套餐实际提供哪些周期，再比较每次应付金额和自己能接受的付款安排。表中的 KVM 参考价格为年付，CN2 GIA-E 列有季付和年付，香港系列列有月付和年付。不同周期并非每个产品都有，也不应假定续费金额与首次支付完全相同；提交订单前查看页面说明。

### 购买后还能换机房吗？

参考资料称多数套餐支持通过 KiwiVM 切换，香港系列则为香港专属。具体能否切换、可选位置和当前费用取决于所购产品及面板显示。切换可能改变 IP；操作前保存数据，并检查需要更新连接地址的地方。

### 退款需要注意什么？

参考资料提到新账户购买后 30 天内可申请退款，但这不应理解为所有订单都无条件退款。购买或申请前，应核对服务商当时的退款政策、账户资格及申请方式；不要以退款一定成功为前提决定购买。
